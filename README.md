## 🚀 Featured Projects

### 🍽️ [Tık Menüm](https://tikmenum.com) — Restaurant QR Menu SaaS &nbsp;`Live in production`
A web-based SaaS platform for restaurant QR menus, actively used in the field. Three role-based interfaces: customer menu, restaurant admin panel (products, categories, QR codes) and a super-admin panel.
**Stack:** React • Tailwind CSS • Supabase

### 🏥 [AI-Integrated Hospital Appointment System](https://github.com/OmerFarukkavugubuyuk/Hospital_Appointment_Service)
Full-stack hospital appointment and administration system with a **Gemini API** assistant that routes patients to the right department based on their complaint. Includes patient, doctor and chief physician (super admin) panels.
**Stack:** C# • .NET 8 • Google Cloud Firestore • Firebase Authentication

### 📹 [Serverless P2P WebRTC Video Call](https://github.com/OmerFarukkavugubuyuk/Serverless-P2P-WebRTC-Video-Call)
Peer-to-peer video calling built with WebRTC, no dedicated media server required.
**Stack:** HTML • JavaScript • WebRTC

### 🤖 [Job Application Bot](https://github.com/OmerFarukkavugubuyuk/Job_Application_Bot)
Automation bot that helps streamline job applications.
**Stack:** Python

### 🛡️ [Regedit Antivirus Demo](https://github.com/OmerFarukkavugubuyuk/Example_Virus_and_Anti_Virus_Program_on_Regedit)
